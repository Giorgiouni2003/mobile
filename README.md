# Ninja Frog Adventure

> Platformer 2D in stile Super Mario Bros, sviluppato per il corso di Mobile Computing. Il giocatore controlla Ninja Frog (asset Pixel Adventure) attraverso diversi livelli, superando ostacoli e nemici con l'aiuto di power-up, fino a raggiungere la fine dell'avventura.

- **Topics**: Physics, Level Design, Cross-Platform Input, Mobile Development
- **Version**: Unity 6 (6000.4.3f1)
- **Piattaforme target**: Android e iOS (app multipiattaforma, testata su device reale)

## Livelli

- `1-1`: livello introduttivo
- `1-2`: livello finale

## Feature

-  Level design multi-livello con progressione tramite flag pole
-  Controlli touch on-screen (per giocare su smartphone/tablet)
-  Musica di sottofondo ed effetti sonori
-  Menu iniziale
-  Testo introduttivo (storia) e testo di fine gioco
-  Login e registrazione con email reale

## Come aprire il progetto

1. Installa Unity Hub
2. Apri Unity Hub e aggiungi questo progetto (Add project from disk)
3. Apri il progetto con Unity 6000.4.3f1 (o versione compatibile)
4. Scena iniziale: `Assets/Scenes/1-1.unity`
